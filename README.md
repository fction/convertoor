# Convertoor

Личная медиастудия для конвертации и сжатия изображений, аудио и видео. Файлы обрабатываются в браузере. [Открыть студию](https://convertoor.vercel.app/) · [Вход через GitHub Pages](https://fction.github.io/convertoor/) · [Исследование FreeConvert и план разработки](docs/PLAN.md)

| Класс | Выходы |
|---|---|
| Изображение | PNG, JPEG, WebP. Для анимированных или многостраничных файлов экспортируется первый кадр. |
| Аудио | MP3, WAV, FLAC, Ogg Vorbis. |
| Видео | MP4/H.264, WebM/VP8. При наличии звуковой дорожки доступен отдельный аудиоэкспорт. |

Студия определяет формат по содержимому и читает исходный файл частями. Видео больше 100 МиБ поддерживается. При экспорте в MP4 или WebM кодек пишет блоки во временный файл на диске устройства через файловую систему браузера (OPFS). После обработки нажмите **Download file**, чтобы сохранить копию. **Remove** освобождает временный файл. Для сохранения видео нужны свободное место на диске и браузер с поддержкой OPFS, Web Locks и Service Workers. Если нажать Remove во время скачивания, файл удалится после завершения передачи. Оперативная память требуется для кадров и работы кодека. Изображения и аудио экспортируются в памяти. При первом открытии файла вкладка загружает движок WebAssembly размером около 32 МБ. Максимальная длительность аудио и видео составляет 30 минут.

Узкие видео сохраняют отображаемые пропорции с учётом формы пикселя и поворота. Для экстремально узкого кадра профиль может сохранить более длинную сторону. Студия показывает это в настройках до экспорта.

## Доступ владельца

В Windows логин владельца — **fction**. Для первоначальной установки скрипт генерирует пароль из 24 случайных байтов. Пароль и настройки доступа сохраняются в зашифрованном Windows DPAPI файле под текущей учётной записью, вне репозитория. Следующая команда копирует пароль в буфер обмена из каталога проекта.

```powershell
.\scripts\access.ps1 CopyPassword
```

## Локальный запуск в Windows

Требуется Node.js 22 или новее и PowerShell. Сервер запускается на локальном интерфейсе. [Локальный адрес после запуска](http://127.0.0.1:4173)

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run build
.\scripts\access.ps1 Initialize
.\scripts\access.ps1 Start
```

Для другой ОС задайте переменную окружения `CONVERTOOR_ACCOUNT` с JSON-записью, созданной функцией `newAccount` из `lib/account.mjs`, затем выполните `npm start`. Для проверки логики выполните `npm test`.

## Размещение

Исходники находятся в публичном репозитории. Vercel собирает ресурсы командой `npm run build` и обслуживает вход и закрытые маршруты через `api/gateway.mjs`. В production задаётся sensitive-переменная `CONVERTOOR_ACCOUNT`. Она содержит логин, соль, проверочный хеш и отдельный ключ подписи. Развертывания без неё остаются закрытыми. Скрипт `access.ps1 Publish` добавляет настройку в привязанный проект Vercel. Изменения переменных вступают в силу после нового развертывания. Статическая точка входа GitHub Pages находится в `main/docs`.

Для сеансов подключите к production приватное хранилище Vercel Blob. При интеграции Vercel задаёт `BLOB_READ_WRITE_TOKEN`. Студия хранит хеш билета и состояние сеанса. Перед каждой выдачей закрытого ресурса сервер читает состояние напрямую из хранилища. Успешный выход немедленно отзывает билет во всех экземплярах сервера. Локальному серверу достаточно памяти одного процесса.
